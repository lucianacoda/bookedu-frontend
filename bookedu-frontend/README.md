# Biblioteca Escolar (Front-End)

Interface de usuário para o MVP do sistema de biblioteca escolar. Construída com HTML, CSS e Vanilla JavaScript, a aplicação faz chamadas para as quatro rotas obrigatórias (GET, POST, PUT, DELETE) da API principal.
